# Spikes

Notes from spikes (`workflows/spike.md`): one question answered by trying, on a throwaway
`spike/<slug>` branch that is never merged. The note is what survives — the code does not.

- One file per spike: `NNNN-<slug>.md` from `TEMPLATE.md`; NNNN = highest here + 1.
- A note is written once and not rewritten; a later spike on the same topic gets a new note
  that links the old one.
- The recommendation ends up in exactly one durable place: an ADR, a backlog row, a spec — or
  nowhere, when the answer is "no".
